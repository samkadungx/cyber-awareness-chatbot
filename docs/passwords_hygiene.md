Password Hygiene

Password hygiene is the set of habits that keep your passwords secure — preventing unauthorized access, data breaches, and identity theft.



Why It Matters

Compromised credentials are a leading cause of data breaches.



Reusing passwords means one breach can compromise all your accounts.



Attackers use credential stuffing — testing stolen login combos across many sites.



A single compromised employee account can expose an entire organization.



Core Best Practices

1\. Create strong, unique passwords

At least 12 characters, mixing uppercase, lowercase, numbers, and symbols.



Avoid dictionary words, personal info, and common substitutions.



Every account gets its own password — no variations of a base password.



2\. Never reuse passwords

One reused password = every account vulnerable at once.



Treat each password like a separate key for a separate lock.



3\. Use a password manager

Stores all credentials in an encrypted vault unlocked by one master password.



Autofills logins, syncs across devices, and removes the temptation to reuse.



Far safer than browser saving, spreadsheets, or written notes.



4\. Enable multi-factor authentication (MFA)

Adds a second layer even if your password is stolen.



Prioritize email, banking, and work accounts.



Authenticator apps are safer than SMS codes.



5\. Change passwords after a breach

Act immediately — don't wait for a forced reset.



Check Have I Been Pwned for known breaches.



Change the password everywhere it was reused.



6\. Watch for phishing

Verify URLs before entering credentials.



Be suspicious of urgent password-reset or verification emails.



Navigate to sites directly instead of clicking links.



7\. Share passwords securely

Never share via email, text, or notes.



Use your password manager's encrypted sharing features.



Change shared passwords afterward; never share your master password or MFA codes.



8\. Use a password generator

Humans create predictable patterns; generators create true randomness.



Built into most password managers — set length and character types.



9\. Audit passwords regularly

Every few months, check for weak, reused, or breached credentials.



Fix critical accounts first (email, banking, work).



10\. Follow your organization's password policy

Policies set baseline security standards.



A password manager makes compliance automatic.



Key Takeaway

Password hygiene is cumulative — each good habit strengthens the others. Strong, unique passwords + a manager + MFA + regular audits = a robust defense against most attacks.



# Password Hygiene



\## What is a strong password?

A strong password is one that is:

\- At least 12 characters long

\- Unique for every account (never reused)

\- Not based on personal information (birthdays, names)

\- Stored in a password manager
